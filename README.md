# Simple Interest Calculator

A simple, lightweight script/application to compute simple interest based on the principal amount, annual interest rate, and time period in years.

## Formula

The simple interest is calculated using the standard formula:

$$A = P (1 + rt)$$

Where:
* **$P$** = Principal amount
* **$r$** = Annual interest rate (in decimal form, e.g., $5\% = 0.05$)
* **$t$** = Time period in years
* **$A$** = Total accumulated amount (Principal + Interest)

Interest earned alone is:
$$\text{Interest} = P \times r \times t$$

## Features
- Fast and simple arithmetic calculation
- Command-line / script interface
- Takes user input for principal, rate, and duration
